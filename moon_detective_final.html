CASE FILE 02 / 빛의 단서

달은 빛을 만들지 않아요.
태양빛을 반사하죠.

달의 둥근 표면 중 태양을 향한 절반은 언제나 빛을 받습니다. 지구에서 그중 얼마나 보이는지가 중요해요.

🔍 조사 기록

달의 어두운 부분은 항상 지구 그림자일까요?

아니에요. 달에는 태양빛을 받는 낮과 받지 않는 밤이 있어요. 지구에서 달의 밤 부분을 바라보면 어둡게 보일 수 있죠.

기억할 것
일반적인 달의 위상 변화는 지구 그림자 때문이 아닙니다.

CASE FILE 05 / 두 사건 비교

원인은 다르지만,
둘 다 달의 모양을 바꿔 보여요.

두 현상을 한눈에 비교해 보세요. 위상은 달의 밝은 면을 보는 각도, 월식은 실제 지구 그림자 통과 여부가 핵심입니다.

🌙 평소의 달의 위상 변화

원인: 태양빛을 받은 면을 지구에서 보는 방향이 달라짐
시기: 약 29.5일마다 한 주기
지구 그림자: 필요 없음

🌘 특별한 날의 월식

원인: 달이 실제로 지구 그림자 속으로 들어감
시기: 보름달 무렵, 궤도 정렬 조건이 맞을 때
지구 그림자: 현상의 직접적인 원인

* 궤도, 거리, 크기와 그림자 범위는 개념 이해를 위해 단순화한 모식도입니다. 실제 태양·지구·달의 크기 및 거리는 비례하지 않습니다.
